### 0-1. 지시문과 다른 사실 하나 — 성취기준은 "105개"가 아니라 **48개**

`통합교과.chunks.jsonl`은 **105건**이지만 성취기준(`chunkType = standard`)은 **48개**다. 나머지는 성취기준 해설 21 · 영역 핵심 아이디어 12 · 내용 요소 12 · 적용 시 고려 사항 12이다(교육부 별책 대조 완료본). 바른 생활 16 · 슬기로운 생활 16 · 즐거운 생활 16, 영역은 「우리는 누구로 살아갈까 / 어디서 살아갈까 / 지금 어떻게 살아갈까 / 무엇을 하며 살아갈까」 네 가지(영역마다 4개). 코드 꼴은 `[2바01-01]`·`[2슬01-01]`·`[2즐01-01]`. 기준표(`content/_ref/standards-2022.json`)에는 이 **48개**를 더했다(214 → **262**).

읽는 법: 통합교과는 **대부분 교사가 직접 하는 활동(그림·노래·놀이·만들기)**이라 영상 없이 진행되는 차시가 많다. 영상 후보는 ① 주제를 **알고 느끼는 자료**(자연·우리나라·세계·인물·마을 사람들) ② **안전·건강 습관**(공공 어린이 영상) ③ 그림책·이야기(공공 도서관·교육청의 동화 구연)로 모은다. 그래서 단원마다 영상 수가 고르지 않을 수 있다(§8-1).

## 2. 꾸러미 설계

### 2-1. 단원(주제) = 꾸러미 1개 — id·성취기준

id = `in` + 학년 + 학기 + **학기 안 단원 번호(1~4)** + `1`(소단원 자리, 과학처럼 고정). 단원 번호는 교과서 차례 순서다(지도서 차례로 한 번 더 확인 — §9 ⑨). 성취기준은 정리본이 가리키는 단원 코드 3개(바·슬·즐)이다. **각 코드는 한 꾸러미에만** 붙는다(48코드 ↔ 16단원 = 3 × 16, 겹치지 않음).

- `sort_order`: 1 고정.

### 2-2. 꾸러미 유형 — 활동형(`activity`)

통합교과는 "핵심 용어"보다 **경험·활동**이 중심이므로 **활동형(생각열기·탐구하기·확장하기 + 단계 질문)**을 기본으로 한다. 단계 질문은 정리본 차시 목표를 1·2학년 말로 풀어 쓴다. 핵심 용어는 `intro.concepts`에 3~5개(예: 학교 — 안전·약속·친구 / 마을 — 마을·이웃·교통 안전).

### 2-3. 꾸러미 안 단계(stage) — 정리본 "주제" 차시를 세 덩어리로

차시 번호는 정리본 `lessons[].lessonNo`. 영상은 **차시 이름이 아니라 단계 질문**에 맞춰 놓는다.

| 단계 | 하는 일 | 주제 차시에서 | 질문 예(학교) |
|---|---|---|---|
| 생각열기 | 주제를 만나는 호기심 — 그림책·이야기·경험 떠올리기 | 앞쪽 3~5차시(그림책 만나기 등) | 학교는 어떤 곳일까? |
| 탐구하기 | 알아보고 익히기 — 조사·관찰·익힘·안전 습관 | 가운데 8~12차시 | 학교에서 안전하고 즐겁게 지내려면? |
| 확장하기 | 나누고 표현·실천하기 — 친구·다른 곳으로 넓히기 | 뒤쪽 4~6차시(전시·약속·다짐) | 친구와 함께 지내려면? |

## 3. 수집 기준

### 3-1. 출처 등급(`content/channels.yaml`)

도덕·실과 계획서 §3-1과 같다 — **public·edu 우선 → press → personal은 다른 자료가 없을 때만(사유 `note`, 운영자 확인)**. 통합교과는 어린이용 공공·교육 채널이 풍부하므로(보건복지부·행정안전부·소방청·교육청·국립 기관·EBS 키즈) personal 비중을 도덕·실과보다 더 낮게 잡는다(목표: public·edu가 채택 영상의 80% 이상).

### 3-2. 공개·재생 조건

도덕·실과와 같다 — 임베드 허용 · 국내 재생 · 연령 제한 없음 · 비공개 아님 · **쇼츠 제외**(운영자 10/17 지시를 따름) · 재생 목록은 개별 영상 주소로 · 광고·협찬·제품 홍보 제외. 모두 YouTube Data API(`videos.list`)로 후보 전부를 확인하고, 쇼츠는 `youtube.com/shorts/<id>` 응답으로 가른다.

### 3-3. 1·2학년 어린이 눈높이·안전 기준(도덕·실과보다 엄격)

| 기준 | 내용 |
|---|---|
| 길이 | 1~5분. 1분 미만은 수업 전 동기 유발로만, 5분 넘으면 구간 지정 |
| 말·화면 | 말이 빠르거나 자막이 많지 않을 것. **한글을 막 익히는 학년이라 글자를 읽어야만 이해되는 영상은 제외.** 그림·소리·움직임으로 전달되는 영상 선호 |
| 안전 | 무섭거나 자극적인 장면(사고 재현의 피해 장면, 비명·충격 음향, 선정적 자막) 제외. 교통·화재·재난 영상은 **예방·대처 행동을 보여 주는 것**만이고, 주제 중심 지시(10/17)로 **채택 우선순위는 낮다**(안전 차시 영상은 보류, 운영자가 승격할 때만) |
| 상업성 | **광고·협찬·제품 홍보, 상업 캐릭터 채널(장난감·웹툰·게임 연계) 제외.** 단 보건복지부·EBS 등 **공공·교육 채널이 만든 캐릭터 영상**은 허용 |
| 얼굴 노출 | 사람 얼굴 노출이 적은 영상 선호(애니메이션·사물·풍경·손 시범). **학생·아동이 출연**하는 영상은 공공·교육청·학교 공식 채널 것만, 개인 채널의 아동 출연 영상 제외 |
| 음원 | 동요·노래 영상은 **공공·교육 채널이 올린 것**만(국립국악원·국립어린이청소년도서관 등). 음원 저작권이 있는 상업 음원 영상 제외 |

| 정치·종교·기업 | 특정 종교·정파·기업 홍보 영상 제외 |

### 3-4. 교육과정 적합

- 성취기준 원문(chunks)과 정리본 차시 목표(`goalGist`) 중 어느 것에 맞는지 후보 기록의 `basis_code`·`basis_lesson`에 적는다(코드 + 차시 번호).
- 정리본 `unitNotes.misconceptions`·`cautions`에 어긋나는 영상 제외(예: 학교 — 가족 형태를 하나로 전제하는 영상, 우리나라 — 북한을 일방적으로 적대·비하하는 영상).
- 사건·사고·재난 영상은 피해 장면이 없고 예방 행동을 알려 주는 공공 영상만.

### 3-5. 뉴스·언론 영상

도덕·실과 §3-5(대구 지역 언론 우선, 사례·캠페인·탐방 꼴만)와 같으나 통합교과는 뉴스를 거의 쓰지 않는다 — 사고 뉴스는 피해 장면 때문에 대체로 제외하고, 마을·계절·자연 단원에서 **대구 지역 어린이 대상 공공 영상**(대구TV·구청 채널·교육청)이 있으면 먼저 본다(`local: 대구`).

### 3-6. 쓰임 표지 규칙

도덕·실과와 같다(수업 전 1~3분 / 수업 중 2~5분 / 수업 후 / 배경지식). 통합교과는 **수업 중**을 가장 많이, 안전 영상은 `수업 중`.

→ ④ 운영자 판정(출처가 확실하지 않거나 personal인 것은 운영자에게 묻기) → ⑤ npm run import(채택 → 꾸러미 YAML)

## 6. 준비할 것

### 6-1. 기준표 — 통합교과 48코드 추가 *(완료, 이 브랜치)*

통합교과는 어린이용 공공·교육 채널이 많아 `content/channels.yaml`에 없는 채널이 꽤 나올 것이다(보건복지부 어린이·행정안전부·소방청·질병관리청·기상청·국립국악원·국립한글박물관·국립어린이청소년도서관·국립생태원·한국전력·한국잡월드·EBS 키즈 …). 도덕·실과 세션처럼 `videos`가 채운 채널 가운데 등급 표에 없는 것을 **후보 판정 뒤 한꺼번에 운영자가 확정**한다(`npm run check`가 알려 준다). 단체(굿네이버스·그린피스·국제앰네스티 등)는 personal.

### 6-4. YouTube Data API 키

`edu-kit/.env`의 `YT_API_KEY`(저장소 밖, `.gitignore`). 도덕·실과 작업과 같은 키를 쓴다. 후보 수집은 `search.list`(100 단위/호출)가 대부분이라 하루 할당(1만 단위)을 감안해 **채널 `playlistItems`(1 단위)와 `videos.list`(1 단위)를 먼저, 키워드 검색은 단원당 10~15회 안**으로 쓴다.

### 6-6. 수업나래 쪽

- **코드 변경 없음.** 수업나래는 3단계 표4 □ 학습자료에 꾸러미를 **성취기준 코드로** 붙인다. 통합교과 꾸러미가 main에 오르면 `web/`에서 `npm.cmd run kit:pull` → 카탈로그 커밋 → 배포(수업나래 배포 규칙)만 하면 `[2바…]`·`[2슬…]`·`[2즐…]` 코드로 붙는다.
