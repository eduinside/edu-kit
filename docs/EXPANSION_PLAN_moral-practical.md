### 2-1. 도덕 — 1단원 = 1꾸러미(국정 교과서 차례)

- 학기: 교과서 1~4단원 = 1학기, 5~8단원 = 2학기. 단원마다 4차시.

| 핵심 용어 풀이 | 초등 어휘, 1~2문장, "~이에요/예요" 체, 순환 정의 금지, 다른 꾸러미와 같은 용어는 같은 풀이 |
| OX 퀴즈 | 단원당 5~8개, O:X 비슷하게, 사실·개념 관계·자료 해석·생활 적용 고루, "항상·절대"는 근거 있을 때만, X 해설은 바른 사실로. 도덕은 **관점에 따라 답이 갈리는 문장을 만들지 않는다**(가치 판단 문항 금지 — 사실·개념·사례 확인만) |
| 쓰임(`use`) | 수업 전 · 수업 중 · 수업 후 · 배경지식(§3-6) |

## 3. 수집 기준

### 3-1. 출처 등급(`content/channels.yaml`)

| 등급 | 뜻 | 쓰임 |
|---|---|---|
| **public** | 공공기관·공공연구·지자체(교육부 제외) | **우선**. 지도서가 가리킨 기관의 공식 채널부터 |
| **edu** | 교육부·교육청·교육연구기관·EBS | **우선** |
| **press** | 언론·방송 | public·edu로 못 채우는 사례·뉴스에. **대구 지역 언론을 먼저 찾는다**(§3-5) |
| **personal** | 개인·기업·단체(NGO 포함) | **다른 자료가 없을 때만**(운영자 결정 §9-④), 후보 기록의 `note`에 사유를 적고 운영자가 따로 본다. 단체(유니세프·WWF 등)도 이 등급이므로 같은 규칙 |

채널은 `npm run videos`가 채우고 `npm run check`가 등급 표에 없는 채널을 알려 준다. 새 채널은 §6-4대로 등급 표에 더한다.

### 3-2. 공개·재생 조건

- **임베드 허용**(임베드 차단은 교체가 먼저, 대안이 없을 때만 `embed: false`)
- **국내 재생 가능**, **연령 제한 없음**, 비공개·일부 공개 아님 — `npm run videos`가 판정(키 있으면 Data API, 없으면 oEmbed)
- 재생 목록·쇼츠는 개별 영상 주소로 바꾼다. 쇼츠는 세로 화면이라 가능하면 일반 영상을 고른다
- 광고·협찬·제품 홍보가 본문인 영상 제외(기업 채널의 공익 캠페인은 personal 규칙으로)

### 3-3. 길이

| 길이 | 처리 |
|---|---|
| **2~8분** | 권장 |
| 8~15분 | `start`/`end` 구간 필수(핵심 2~8분) |
| 15분 넘음 | 배경지식(교사용)으로만, 구간 필수 |
| 1분 미만 | 수업 전 동기 유발로만 |

### 3-4. 교육과정 적합

- **성취기준 원문**(chunks)과 **정리본 차시 목표**(`goalGist`) 중 어느 것에 맞는지 후보 기록의 근거 칸에 적는다(코드 + 차시 번호).
- 도덕: 가치·덕목을 **사례·이야기·실천 모습**으로 보여 주는 영상. 특정 종교·정파·기업의 주장을 담은 영상 제외. 위인·인물 영상은 사실 전달 중심(공공·교육·언론)만.
- 실과: **원리·과정·안전**을 보여 주는 영상(조리·바느질·재배·조립·코딩). 출판사 실습 동영상은 저작물이라 **쓰지 않고**, 같은 내용을 공공·교육 채널에서 찾는다. 상품 리뷰·쇼핑 연계 영상 제외.
- 정리본 `unitNotes.misconceptions`(오개념)·`cautions`(유의점)에 어긋나는 영상 제외(예: 도덕5-7 "한 사람의 실천은 소용없다"는 식의 무력감을 주는 영상).

### 3-5. 뉴스·언론 영상 — 대구 지역 언론 우선(운영자 결정 §9-⑤)

- press 후보를 찾을 때 **먼저 대구 지역 언론**을 검색한다(`핵심어 + 대구`, 채널 안 검색): 등급 표에 이미 있는 대구MBC뉴스 · dgmbcnews · 대구MBC Program · KBS뉴스 대구경북 · TBC뉴스 · 매일신문 · 영남일보TV · LG헬로비전 대구경북 · ch B tv 대구 · 푸른방송뉴스채널, 그리고 public인 대구TV(대구광역시) · 구청 채널(수성·동구·서구·북구·달성). 지역 사례(대구 봉사단·대구 학교 환경 실천·대구 스마트팜 등)가 있으면 전국 뉴스보다 앞에 둔다. 후보 기록에 `local: 대구`를 적어 발행 뒤 통계를 낼 수 있게 한다.
- 전국 언론은 그 다음(YTN·KBS News·연합뉴스TV·스브스뉴스·비디오머그·JTBC 등).
- 사건·사고·재난 영상은 **피해 장면·자극적 자막**이 있으면 제외. 인권·생명 단원은 피해자 노출이 없는 것만.
- 특정 인물·집단을 비난하는 보도, 논쟁 중인 사안의 한쪽 주장만 담은 보도 제외.
- 뉴스는 **사례 소개·캠페인·현장 탐방** 꼴을 고른다(예: 플로깅 청년, 어린이 봉사단, 스마트팜 현장).

### 3-6. 쓰임 표지 규칙

| 쓰임 | 어떤 영상 | 길이 |
|---|---|---|
| **수업 전** | 동기 유발·문제 상황·사례 한 토막 | 1~3분 |
| **수업 중** | 개념·원리 설명, 시범·과정, 자료 해석 | 2~8분 |
| **수업 후** | 실천 사례·확장·다른 지역·세계 | 2~8분 |
| **배경지식** | 교사용 다큐·강연·심화(학생 시청 전제 아님) | 구간 지정 |

꾸러미 하나에 네 쓰임이 고루 들어가도록 하되 수업 중을 가장 많이 둔다.

### 3-7. 저작권·초상권

- 지도서 본문·활동지·삽화는 옮기지 않는다(원문은 수업나래 git 밖). 영상 `desc`는 우리 말로 새로 쓴다.
- **학생·아동이 출연**하는 영상은 공공·교육청·학교 공식 채널 것만. 개인 채널의 아동 출연 영상 제외.
- 실명 인물(위인·공인·피해자) 영상은 사실 보도·공식 기록만, 사생활·추모 영상 제외.
- 음원이 핵심인 영상(노래·공연)은 제외(도덕 통일·인류애 단원에서 유의).
- 지도서가 가리킨 영상이라도 **해당 채널이 원 저작자가 아닌 재업로드**면 제외하고 원 채널을 찾는다.

## 4. 수집 절차 — 코드 기반, Claude와 대화로(운영자 결정 §9-⑦)

협업 시트는 쓰지 않는다. 후보는 저장소 안 파일에 쌓이고, 판정은 운영자가 Claude와 대화하며(또는 파일의 `verdict`를 고쳐) 내린다.

```
① 꾸러미 머리 초안(Claude) → ② 후보 수집(Claude: 검색어 표·지도서 참고 자료·공식 채널) → ③ 1차 선별(Claude, §3)
→ ④ 운영자 판정(대화 또는 verdict 칸) → ⑤ 꾸러미 YAML(Claude) → ⑥ npm run videos → ⑦ check → ⑧ report → ⑨ 브랜치 push·미리보기 → ⑩ 운영자 확인 → main(= 공개)
```

| 단계 | 누가 | 하는 일 | 산출물 |
|---|---|---|---|
| ① 머리 초안 | Claude | chunks·정리본·진도표에서 id·제목·학년·학기·코드·핵심 아이디어·핵심 질문·유형·단계·용어 후보 | `content/_candidates/<id>.yaml`의 `kit:` 부분(§5-1) |
| ② 후보 수집 | Claude(세션 안 브라우저로 유튜브 채널 검색; 지도서 참고 자료 주소부터) | 꾸러미당 **후보 20~30편**(채택 12~20 목표). 등급·길이·제목·채널을 적는다 | 같은 파일 `candidates:` 행 |
| ③ 1차 선별 | Claude | §3 기준 점검(등급·길이·적합·선정성·지역), 겹침 제거, 쓰임·구간 제안, 설명 초안. **실제로 재생해 보지 못한 것은 `verdict: 확인필요`** | `verdict`(추천·보류·제외·확인필요) + `note` |
| ④ 판정 | 운영자 | 추천·확인필요 영상을 보고 `채택/보류/제외`로. 대화로 "c03 빼고 c08 채택"처럼 말하면 Claude가 파일에 적는다 | `verdict`·`reviewer` |
| ⑤ YAML | Claude | `verdict: 채택` 행만 `content/kits/<id>.yaml`의 `items`로(§5-1 변환 규칙). 용어 풀이·OX 초안(§2-3) | 꾸러미 YAML |
| ⑥ 영상 점검 | Claude | `npm run videos -- <id>` → `channel`·`status`. 문제 영상은 ④로 되돌림 | YAML 갱신 |
| ⑦~⑧ 점검·보고 | Claude | `npm run check`(오류 0) · `npm run report` · 새 꾸러미 `npm run og` · 여러 꾸러미면 `npm run changes` | 보고서 |
| ⑨~⑩ 발행 | Claude → 운영자 | 브랜치 push → Pages 미리보기 → 운영자 표본 확인 → main 병합 → kit.dgedu.link(완성되는 학년부터 바로 공개, §9-⑩) | 배포 |

- 가져오기 스크립트(`scripts/import-candidates.ts`, §6-3)는 후보 파일 → 꾸러미 YAML 변환을 맡는다. 시범 첫 꾸러미는 Claude가 손으로 옮겨도 되지만, 둘째부터는 스크립트로 한다(`kitToYaml` 규칙 준수).
- 후보 파일은 발행 뒤에도 남긴다(판정 근거 기록). `npm run data`·`check`는 `content/kits/`만 읽으므로 `_candidates/`가 빌드에 섞이지 않는다(§6-3에서 확인).

## 5. 후보 기록 파일 양식과 검색어 표

### 5-1. `content/_candidates/<kit_id>.yaml`(열 이름 고정 — 가져오기 스크립트가 이 키를 읽는다)

```yaml
kit:                        # 꾸러미 머리(① 초안) — 꾸러미 YAML의 같은 이름 칸으로 간다
  id: mo5271
  title: 7. 지구의 내일을 심는 우리     # 도덕: 교과서 차례 · 실과: 묶음 내용 이름(§2-2)
  grade: 5
  sem: 2학기
  subject: 도덕
  unit: 7단원                # 도덕: 교과서 단원 · 실과: 영역 이름
  unit_no: 7
  flow: activity             # activity · flow
  codes: ["[6도04-01]"]      # 원문은 기준표(standards-2022.json)에서 자동
  core_idea: …
  core_question: …
  stages:                    # 흐름형: 용어 이름 목록 · 활동형: name·question
    - name: 생각열기
      question: 지구는 지금 어떤 위기를 겪고 있을까?
  concepts:                  # 용어 후보(풀이는 ⑤에서 Claude 초안 → 운영자 검수)
    - 기후 위기
  source_notes: 정리본 도덕5.국정.u7 · 지도서 참고 자료 10편   # 근거 메모(YAML에 안 들어감)

candidates:                 # 영상 후보 하나 = 한 항목
  - cand_no: c01            # 꾸러미 안 일련번호 — 대화·판정용. YAML key는 변환 때 새로 매긴다(v1…)
    stage: 생각열기
    title: 지구 환경 위기, 시간이 얼마 남지 않았다      # 목차 제목(우리 말)
    video_title: …          # 유튜브 원제(다를 때만)
    url: https://www.youtube.com/watch?v=…           # 개별 영상 주소만
    channel: 비디오머그     # 수집 때 본 이름(참고 — 정본은 npm run videos가 채움)
    channel_grade: press    # public · edu · press · personal
    local: 대구             # (선택) 대구 지역 언론·기관이면
    duration: "1:53"
    start: 0                # (선택) 초
    end: 0                  # (선택) 초
    use: 수업 전            # 수업 전 · 수업 중 · 수업 후 · 배경지식
    basis_code: "[6도04-01]"
    basis_lesson: 1차시 환경 위기 사례 조사
    desc: …                 # 1문장, 우리 말
    verdict: 추천           # Claude 1차: 추천 · 보류 · 제외 · 확인필요 → 운영자: 채택 · 보류 · 제외
    reviewer: 운영자        # 판정 확정한 사람
    note: …                 # 제외 사유 · personal 사유 · 확인할 것
```

변환 규칙(`import-candidates`): `kit.id`로 꾸러미 파일을 만들거나 찾고, `verdict: 채택`인 후보만 `items`에 넣는다. 같은 `url`이 두 항목이면 하나만. `stage`가 `kit.stages`에 없으면 멈춘다. `cand_no`·`channel`·`channel_grade`·`local`·`duration`·`basis_*`·`reviewer`·`note`·`verdict`는 꾸러미 YAML에 **넣지 않는다**(`npm run check`가 모르는 칸을 오류로 본다). 기존 꾸러미를 고칠 때는 후보에 `key`를 적어 그 key로 맞춘다(새 항목은 비움). `channel`·`status`는 비워 두고 `npm run videos`가 채운다.
