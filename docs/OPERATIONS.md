# 수업꾸러미 운영 절차 — 꾸러미 파일 + Claude

> 2026-10-02부터 콘텐츠 정본은 **`content/kits/<id>.yaml`**(꾸러미 하나 = 파일 하나)이다.
> 구글 시트 발행(GAS)은 은퇴했다. 시트는 읽기 전용으로 보관하며, 시트에서 발행하지 않는다.
> 전환 배경·결정: [IMPROVEMENT_PLAN_claude-ops.md](IMPROVEMENT_PLAN_claude-ops.md)

## 1. 한눈에

```
요청(운영자 말 · 협업 시트 · 교사 설문)
  → Claude가 content/kits/*.yaml 수정
  → npm run check (오류 0)  → npm run report (변경 보고서를 운영자에게)
  → 작업 브랜치 커밋·push → Cloudflare Pages 미리보기 주소에서 운영자 확인
  → main 병합 → kit.dgedu.link 자동 배포
```

| 명령 | 하는 일 |
|---|---|
| `npm run check` | 발행 전 점검(§4). 꾸러미만 보려면 `npm run check -- so5121 sc5111`. 오류가 있으면 종료 코드 1 |
| `npm run report` | 변경 보고서 — 작업본을 `origin/main`과 꾸러미별로 비교. 기준을 바꾸려면 `npm run report -- <커밋>` |
| `npm run videos` | 영상 점검(§3-4). 결과를 YAML의 `channel`·`status`에 적는다 |
| `npm run data` | YAML → `data/*.json`(빌드·개발 서버가 자동으로 돌림). 형식 오류가 있으면 실패 |
| `npm run og` | 꾸러미 공유 카드(`public/og/<id>.png`). **새 꾸러미·제목 변경 때만**, 결과를 같은 커밋에 |
| `npm run dev` / `npm run build` | 로컬 확인 / 배포 빌드 |

## 2. 꾸러미 파일 형식

```yaml
id: so4111                 # 파일 이름과 같아야 함. 공유 링크 kit.dgedu.link/so4111 · 조회수 키 — 한 번 정하면 바꾸지 않는다
title: 1-1. 지도로 본 우리 지역
grade: 4                   # 3 · 4 · 5 · 6
sem: 1학기                 # 1학기 · 2학기
subject: 사회              # 사회 · 과학
unit: 1단원                # 대단원(홈 화면의 대단원 거르기에 쓰인다)
unit_no: 1
flow: flow                 # flow(핵심 용어 흐름형) · activity(활동형)
sort_order: 1              # 같은 학년·학기·교과 안에서 대단원 다음 순서
published: true

intro:                     # 단원 안내(사이트의 첫 화면)
  core_idea: …
  core_question: …
  concepts:                # 핵심 용어 — def가 있어야 사이트에서 눌렀을 때 풀이가 나온다
    - term: 지도
      def: 우리가 사는 땅의 모습을 …
  standards:               # 2022 성취기준 — code·text는 원문 그대로(§4 점검)
    - code: "[4사05-01]"
      text: 우리 지역을 표현한 …

stages:                    # 단계 순서 = 화면 순서
  - 지도                   #   흐름형: 핵심 용어(질문 없음)
  - name: 생각열기         #   활동형: 생각열기 · 탐구하기(또는 탐구하기1·탐구하기2) · 확장하기 + 탐구 질문
    question: 옛날 사람들이 …

items:                     # 영상 — 목록 순서 = 단계 안의 화면 순서
  - key: v1                # 꾸러미 안 고유. 주소 kit.dgedu.link/so4111/v1 — 기존 key는 바꾸지 않는다
    stage: 지도            # stages에 있는 이름
    title: 사회 용어 풀이 - 지도      # 목차 제목
    use: 수업 중           # 쓰임: 수업 전 · 수업 중 · 수업 후 · 배경지식 (흐름형)
    url: https://www.youtube.com/watch?v=MNPr9bSkzLg
    video_title: …         # (선택) 영상 머리 제목이 목차 제목과 다를 때만
    desc: …                # 영상 설명
    start: 30              # (선택) 재생 구간, 초
    end: 95
    embed: false           # (선택) 임베드 차단 영상만 — 뷰어가 "유튜브에서 열기" 카드로 대신 보여 줌
    channel: 대구미래교육연구원   # ← npm run videos가 채움(사람이 쓰지 않음)
    status: 임베드차단     # ← npm run videos가 문제 있을 때만 채움

quiz:                      # 개념 확인 OX — 단원당 5~8개 권장, 화면에는 무작위 2문제
  - statement: 지도에서 기호의 뜻은 범례를 보면 알 수 있다.
    answer: O
    explain: 범례는 지도에 쓰인 기호의 뜻을 모아 둔 표예요.
```

- **순서는 목록 순서다.** `sort_order` 숫자는 쓰지 않는다(빌드가 매긴다). 단계·영상·퀴즈를 옮기려면 줄을 옮긴다.
- **새 id 규칙**: 교과 접두사(`so` 사회, `sc` 과학) + 학년 + 학기 + 대단원 + 소단원. 예: 5학년 2학기 사회 3-2 → `so5232`. 과학처럼 소단원이 없으면 `1`.
- **새 영상 key**: 꾸러미 안에서 쓰지 않은 다음 번호(`v24`, `v25` …). 지운 영상의 key는 다시 쓰지 않는다(옛 공유 링크가 엉뚱한 영상으로 가지 않게).
- 문장에 `: `·`#`이 들어가거나 `[`·`"`로 시작하면 따옴표로 감싼다. Claude가 쓸 때는 `kitToYaml`(scripts/content.ts) 규칙을 따른다.
- 이미지·글 항목(`type: image`/`text`)은 아직 YAML 형식에 없다. 빌드 변환(transform.ts)은 지원하므로, 필요해지면 스키마부터 넓힌다.

## 3. 작업별 절차

### 3-1. 단건 수정("so4122 3번 영상 바꿔 줘")
1. 해당 파일을 고친다. 영상을 바꾸면 `url`·`title`·`desc`를 함께 바꾸고, 바꾼 영상의 `channel`·`status`는 지운다(다음 점검이 다시 채움).
2. `npm run check -- <id>` → `npm run report` → §3-5 발행.

### 3-2. 협업 자료 반영(새 단원·대량 수정)
- 협업 시트 양식은 **다음 협업 때 정한다**(개선안 §7-4). 그때 가져오기 스크립트를 만든다.
- 그전까지는 받은 시트·xlsx를 Claude가 읽고 꾸러미 파일로 옮긴다. 옮길 때의 원칙:
  - 키(`id`·`key`)로 맞춘다. 행 순서로 맞추지 않는다(5학년 1학기 영상이 엉뚱한 단원에 들어간 사고가 이렇게 생겼다).
  - 협업본에 원본 탭과 `수정본` 탭이 함께 있으면 요청에서 지정한 탭만 쓴다.
  - 옮긴 뒤 `npm run check`, `npm run videos`(새 영상), `npm run report`.
- 옛 시트 시절 병합 절차는 [archive/CONTENT_BATCH_GENERATION.md](archive/CONTENT_BATCH_GENERATION.md).

### 3-3. 핵심 용어 풀이·OX 퀴즈 쓰기 규칙
**풀이(`def`)**
- 초등학생이 이해할 수 있는 어휘로, 용어마다 1~2문장으로 쓴다.
- 용어를 그대로 되풀이하는 순환 정의는 피한다.
- 역사·사회 개념은 시대와 맥락을 지나치게 단정하지 않는다. 과학 개념은 관찰 가능한 현상과 교과 수준의 인과관계로 설명한다.
- 다른 꾸러미에 같은 용어가 있으면 가능한 한 같은 풀이를 쓴다.

**퀴즈**
- 단원당 5~8개를 쓰고, O와 X를 비슷하게(예: 7개면 3:4) 섞는다.
- 사실 확인·개념 관계·자료 해석·생활 적용을 고르게 담는다.
- "항상·절대·전혀"는 실제로 틀림의 근거가 될 때만 쓴다. 관점에 따라 답이 달라지는 문장은 만들지 않는다.
- X 해설은 "틀렸다"로 끝내지 않고 바른 사실을 적는다.
- 내용은 그 단원의 핵심 아이디어·질문·개념·성취기준·영상 범위 안에서만 쓴다.
- AI가 초안을 쓰면 운영자가 변경 보고서로 검수한 뒤 발행한다.

### 3-4. 영상 점검(운영자가 요청할 때)
- 실행: `npm run videos`.
  - 키: `edu-kit/.env`에 `YT_API_KEY=…` 한 줄(저장소에 안 올라감 — `.gitignore`). 환경 변수가 있으면 그쪽이 먼저다.
  - 키(YouTube Data API v3)가 있으면 시트 시절 「영상 점검」과 같은 기준으로 판정한다: 삭제·비공개 / 비공개 / 연령제한 / 국내차단 / 임베드차단.
  - 키가 없으면 oEmbed로 **임베드차단·삭제·채널만** 본다.
- 결과
  - `channel`(모든 영상)과 `status`(문제 있는 영상만)가 YAML에 적힌다.
  - 실행 기록은 `content/_ref/video-check.json`에 남는다.
  - `npm run check`가 문제를 오류·경고로 보여 준다.
- 처리
  - 교체가 먼저다. 학생이 유튜브 사이트로 나가면 추천 영상·댓글에 노출되기 때문이다.
  - 대체 영상이 없을 때만 임베드차단 영상에 `embed: false`를 둔다.
  - 삭제·비공개·연령제한·국내차단은 링크로도 못 보거나 학생에게 알맞지 않다. **교체하거나 뺀다.**

### 3-5. 발행
1. 작업 브랜치에서 고친다(`main`에 직접 커밋하지 않는다).
2. `npm run check`로 오류 0을 확인하고, `npm run build`가 통과하는지 본다.
3. 새 꾸러미나 제목 변경이 있으면 `npm run og`를 돌린다(`npm run report`가 알려 준다).
4. `npm run report`의 결과를 운영자에게 보인다.
5. 커밋한다. 메시지는 무엇이 바뀌었는지 쓴다(예: `content: so5121 영상 교체 외 3건`).
6. 브랜치를 push한다. Pages가 미리보기 주소 `https://<브랜치>.edu-kit-br4.pages.dev`를 만든다. 이 주소는 확인용이며 정본 주소가 아니다.
7. 운영자가 미리보기에서 표본 단원을 연다. 확인이 끝나면 `main`에 병합하고, `kit.dgedu.link`에 자동으로 배포된다.
8. 배포 뒤 표본 단원 1~2개를 실제 사이트에서 연다.

### 3-6. 되돌리기
- `main`에서 문제 커밋을 `git revert`하고 push한다. Pages가 자동으로 다시 배포한다.
- 꾸러미 파일은 git 이력에 모두 남아 있다.

## 4. 점검 항목(`npm run check`)

| 구분 | 항목 |
|---|---|
| ✗ 오류 | YAML 문법·형식(모르는 칸 이름 포함) · 파일 이름 ≠ id · 빌드 변환에서 빠지는 행 |
| ✗ 오류 | 성취기준: 코드에 긴 줄표(–) · 2022 사회·과학 목록에 없는 코드 · 교과가 다름 · 학년군이 다름(3·4학년 = `[4…]`, 5·6학년 = `[6…]`) |
| ✗ 오류 | 단계 이름 중복 · 영상의 단계가 stages에 없음 · key 중복 · 주소의 공백·제어 문자 · 영상 ID를 못 뽑는 주소 · 구간 끝 ≤ 시작 |
| ✗ 오류 | 영상 상태: 삭제·비공개 / 비공개 / 연령제한 / 국내차단 / URL오류 |
| ⚠ 경고 | 성취기준 원문과 다름(표기만 다름 / 내용이 다름) · 같은 성취기준을 여러 꾸러미가 씀 |
| ⚠ 경고 | **흐름형 꾸러미의 핵심 개념과 영상 단계가 하나도 안 겹침**(다른 단원 영상일 수 있음) |
| ⚠ 경고 | 핵심 용어 풀이 없음 · 용어 중복 · 영상 없는 단계 · 같은 영상 두 번 · 목차 제목 ≠ 영상 제목 · 정해지지 않은 쓰임 값 |
| ⚠ 경고 | 임베드차단인데 `embed: false` 없음 · `embed: false`인데 마지막 점검에서는 재생이 됨 |
| ⚠ 경고 | 퀴즈 2문제 미만 · 정답이 한쪽뿐 · 같은 문장 반복 · 다른 꾸러미와 같은 문장 |
| · 참고 | 쓰임 빈칸 · 채널 미기록 · 풀이 없는 용어 수 · 여러 꾸러미가 같이 쓰는 영상 · 마지막 영상 점검 날짜 |

- 성취기준 기준표: `content/_ref/standards-2022.json`(사회·과학 151개). 수업나래 교육과정 데이터(교육부 원본 별책 대조 완료본)에서 뽑았다.

## 5. 하지 말 것

- **`data/*.json`을 고치지 않는다.** 빌드 산출물이라 다음 빌드에 덮인다.
- **`id`·`key`를 바꾸지 않는다.** 공유 링크와 조회수·좋아요(D1)가 이 값에 묶여 있다.
- **원본 구글 시트에서 발행하지 않는다.** 시트의 발행 버튼·GitHub 토큰은 2026-10-02에 은퇴했다.
- 미리보기 배포는 Pages Preview 환경 바인딩을 쓴다. DEPLOY.md가 권하는 dev D1이 묶여 있지 않으면, 미리보기 조회가 운영 조회수에 섞인다.
